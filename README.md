# 📊 YouTube Data Analysis - Viewership Insights

## 📌 Overview

This project explores YouTube video and channel performance using data analysis techniques. The main objective is to identify patterns in audience engagement and discover the factors that influence video popularity.

The project includes data preprocessing, exploratory data analysis (EDA), visualization, and extracting actionable insights from the dataset.

---

## 🎯 Objectives

- Clean and preprocess YouTube data.
- Explore video categories and engagement metrics.
- Analyze relationships between views, likes, and comments.
- Identify trends affecting video popularity.
- Visualize insights using informative charts.

---

## 🔧 Project Workflow

1. Data Cleaning & Preprocessing
   - Handling missing values
   - Removing duplicates
   - Formatting data types

2. Exploratory Data Analysis (EDA)
   - Distribution of video categories
   - Engagement analysis
   - Correlation analysis

3. Data Visualization
   - Bar charts
   - Scatter plots
   - Statistical summaries

4. Insights & Conclusions

---

## 📊 Key Findings

- Entertainment and Music categories contain the largest number of videos.
- Videos with more likes generally receive more views.
- Audience engagement (likes and comments) is strongly associated with video popularity.
- Some categories consistently achieve higher engagement than others.
- Data visualization makes it easier to identify hidden patterns and trends.
