📌 Overview

This project explores YouTube video and channel performance using data science techniques. The goal was to analyze trends in views and engagement and identify patterns that influence video popularity.

🔧 Key Steps

Data cleaning and preprocessing

Handling missing values and formatting data

Exploratory Data Analysis (EDA)

Visualization of trends using charts and graphs

Analyzing relationships between views, likes, comments, and categories

📊 Insights Extracted

Which video categories get the highest average views

Relationship between likes/comments and total views

Patterns in audience engagement

Trends that may influence video popularity
